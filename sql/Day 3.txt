Questions to solve:
1 Write a query to list department IDs that have fewer than 2 employees, using GROUP BY and
HAVING.
 SELECT DEPTID
 FROM EMPLOYEE
 GROUP BY DEPTID
 HAVING COUNT(*)<=2;

2 Write a query to list department names having at least 2 employees working in them.
 SELECT DEPTNAME, DEPTID
 FROM DEPT, EMPLOYEE
 WHERE DEPT.DEPTID=EMPLOYEE.DEPTID
 GROUP BY  DEPTID
 HAVING COUNT(*)>=2;

3 Write a query to list department names having at least 3 but not more than 5 employees.
  SELECT DEPTNAME, DEPTID
  FROM DEPT, EMPLOYEE
  WHERE DEPT.DEPTID=EMPLOYEE.DEPTID
  GROUP BY DEPTID
  HAVING COUNT(*) BETWEEN 3 AND 5;

4 Write a query to find the hire dates on which 2 or more employees joined (i.e. duplicate hire dates).
  SELECT HIREDATE 
  FROM EMPLOYEE
  GROUP BY HIREDATE
  HAVING COUNT(*) = 2;

5 Write a query to get department ID, department name, and average salary of each department
(you'll need a join here too — attempt it, we'll cover joins properly on Day 12).
  SELECT DEPTID, DEPTNAME, AVG(SAL)
  FROM DEPT, EMPLOYEE
  WHERE DEPT.DEPTID=EMPLOYEE.DEPTID
  GROUP BY DEPTID;
